# Free-to-play titles that are NOT live-service, and must not be capped as if
# they were.
#
# The free-to-play signal is automatic and cheap, and it is wrong in both
# directions. pipeline/data/live_service.txt covers the first direction: PAID
# titles that are live-service (Rust, DayZ) and which price cannot see. This
# file covers the second: FREE titles that are single-player and finishable,
# where the playtime split has the most to say, not the least.
#
# Doki Doki Literature Club is the case that proves the point - a short, free,
# finishable single-player narrative game at rank 71 with 129,582 reviews. It is
# close to an ideal segmentation subject: a large refund-window cohort that
# bounced off a visual novel, and a veteran cohort that finished it and
# understood what it was doing. Capping it as live-service on the grounds that
# it costs nothing would have removed one of the better titles in the catalog.
#
