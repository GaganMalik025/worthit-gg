# QR-5 — verdict word and for-whom line: hand scoring sheet

Scored by hand. No LLM judge, no `candidates.json`, no harness — two known
outputs per game, generated from **identical claims** and an **identical
prompt**, differing only in the synthesis model.

Both outputs passed every code-enforced invariant (4, 11, 12, 13) and QR-4.
Neither needed a retry. This sheet is only about the two things code cannot
check: whether the verdict word is defensible, and whether the for-whom line
does its job.

**A/B is randomised per game and blinded.** The mapping is in `qr5-key.json`
— do not open it until every row is scored.


## Criteria — AUTHORED BY THE DEVELOPER, deliberately left blank

CLAUDE.md: *"Do NOT write the eval rubric wording — the developer authors those
personally (they are interview material). Build the harness and tooling around
them."* The scale below is a skeleton with the wording removed, not an oversight.
Fill in what each score means **before** scoring anything, so the criteria are
not shaped by the outputs.

### QR-5a — verdict word (Buy / Wait / Skip)

Judge against the cohort evidence shown under each game. Not against which model
produced it, and not against the currently committed verdict — that one was
generated by flash and is not ground truth.

    2 = verdict matches what the shown cohort data and flags clearly support
    1 = defensible, but the data could reasonably support a different verdict
        (genuine ambiguity)
    0 = contradicts the shown evidence

### QR-5b — for-whom line completeness

Rule 7 of the synthesis prompt: *"names who should buy this and who should not,
in one sentence. Be specific about the person, not the genre."*

    2 = names both who should buy and who should not, per rule 7
    1 = names one side clearly, only gestures at the other
    0 = addresses only one side

### Decision rule — also yours to set, before scoring

    Proceed with flash-lite as primary if ...
    Keep flash as primary if ...

The stakes, so the rule can be set knowingly: flash carries a free-tier limit of
20 requests per project per day, and one synthesis call is one verdict. Keeping
flash caps the catalog at ~20 verdicts/day. flash-lite has no such ceiling.
